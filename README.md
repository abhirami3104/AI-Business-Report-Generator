AI-Driven Business Sales Analytics and Automated Report Generation using Data Analytics, Machine Learning, and Generative AI.
## Project Overview

This project analyzes retail sales data using data analytics and machine learning techniques. The system extracts insights from business transactions and generates automated business reports using Generative AI concepts.

The goal is to support data-driven decision making by converting raw sales data into meaningful business insights.
